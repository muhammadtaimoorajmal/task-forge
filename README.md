## 📖 Overview

TaskForge is a modern project management application designed to simplify task organization and project tracking for individuals and teams.

The platform provides an intuitive workflow for managing projects, assigning tasks, tracking progress, and maintaining productivity through a responsive and user-friendly interface.

Built with modern frontend technologies and performance-focused architecture, TaskForge emphasizes simplicity, usability, and scalability.

## 🚀 Getting Started

### Prerequisites

* Node.js v18+
* npm

### Clone Repository

```bash
git clone https://github.com/muhammadtaimoorajmal/task-forge.git
cd task-forge
```

### Install Dependencies

```bash
npm install
```

### Run Development Server

```bash
npm start
```

Application will run at:

```bash
http://localhost:3000
```

---

## 📦 Production Build

```bash
npm run build
```

Generated files will be available inside:

```bash
/build
```
